# Teammate Preferences

This is the safe place for each teammate to customize how the skill works. Editing these choices does not change the canonical OHA rules.

- Default destinations: `Trello only`
- Confirmation policy: `Preview before external creation`
- Final response detail: `Concise`
- Response language: `Match the user's language`
- Evidence grouping: `Group multiple files only when they show the same problem`

Allowed destination values after team configuration:

- `Trello only`
- `Linear only`
- `Trello and Linear`

Allowed confirmation values:

- `Preview before external creation`
- `Create immediately when the user explicitly says to create or send`

External write permissions still depend on the AI client and connected account. A preference never overrides a client approval prompt or a disabled/unconfigured destination.
