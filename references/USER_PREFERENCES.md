# Teammate Preferences

This is each teammate's personal starting point. Customize it freely for your own workflow.

- Default destinations: `Trello → OOOHA! - WORKSPACE → FEEDBACK & TESTING`
- Alternative destinations: `Trello`, `Linear`, `both`, or `ask each time`
- Personal Linear destination: `Choose through my Composio connection when needed`
- Confirmation policy: `Preview before external creation`
- Final response detail: `Concise`
- Response language: `Match the user's language`
- Evidence grouping: `Group multiple files only when they show the same problem`

Examples of choices you may save here:

- `Trello only`
- `Linear only`
- `Trello and Linear`
- `Ask which Trello list or Linear team/project to use for each report`
- `Use my chosen Trello backlog list by default`
- `Use my chosen Linear project by default`

Allowed confirmation values:

- `Preview before external creation`
- `Create immediately when the user explicitly says to create or send`

External write permissions still depend on the AI client and connected account. A saved preference never overrides an AI-client approval prompt or access that the teammate does not have.
