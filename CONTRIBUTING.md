# Contributing

Thank you for improving the OHA Feedback skill.

## Personal customization

Edit `references/USER_PREFERENCES.md` in your installed copy for personal choices such as destination, confirmation policy, response language, and response detail.

## Shared fixes

For a change that should help everyone:

1. Fork this repository.
2. Create a focused branch.
3. Update the smallest relevant file.
4. Check that `SKILL.md` still points to every required reference.
5. Open a pull request explaining the problem and the intended behavior.

## Protected OHA rules

Changes to these areas require OHA team review:

- One independent problem equals one issue.
- The official feedback template and field order.
- Verified Trello and Linear destinations.
- Exact-label handling.
- No invented context.
- Evidence-to-issue mapping.
- External-write and uncertain-result safety.

Never commit credentials, Composio tokens, private evidence, customer data, PostHog session links, or private deployment details.
